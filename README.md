# Jardín de Tareas

Calendario de recordatorios con estilo tropical oscuro. Tiene tres categorías:

- **Urgente · Hibisco**: varios avisos antes de la hora y, si quieres, insiste cada hora hasta que la marques.
- **Importante · Mango**: avisa con días de anticipación.
- **Leve · Laguna**: un solo aviso suave.

También incluye fechas clave (cumpleaños, aniversarios, pagos), un resumen cada mañana, horas de descanso sin avisos, ideas para organizarse, consejos para no agotarse y una plantilla visual con la paleta y los íconos.

## Cómo usarlo

1. Abre `jardin-de-tareas.html` en el navegador (doble clic).
2. Toca **Activar avisos** y acepta el permiso.
3. En la sección **Plantilla**, escribe tu nombre y elige tus horarios.
4. Borra las tareas de ejemplo y agrega las tuyas.

Los avisos llegan mientras la página esté abierta, aunque esté minimizada. Las tareas se guardan solo en ese navegador. Para no perderlas, copia tu respaldo una vez al mes desde la sección **Plantilla**.
